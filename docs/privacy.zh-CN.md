# 隐私与本地数据

更新：2026 年 10 月 22 日。[English](privacy.md) · [Français](privacy.fr.md)

Questlog 由 jamezzh7 维护，没有账户系统、分析、广告、模型调用或远程后端，不向开发者收集或上传数据。

应用读取已连接的 Markdown 清单、项目目录内显式关联的计划、用于变更检测的文件元数据，以及详情页中的有限项目说明和 Git 提交元数据。不读取聊天正文。文档说明最多四份摘录，每份文档不超过 2 MB，摘录不超过 1,600 字符。选中的 Markdown 若含私人内容，也可能显示在界面中。

Mac App Store 版需要你通过系统对话框选择项目目录，才获得只读访问权。Codex / Claude Code 的项目索引需要单独选择；索引授权不自动授权其中列出的目录。授权通过安全作用域书签在本机保存，以便重启后恢复。不会修改原项目或工具索引。

连接、清单选择、任务范围、工时、每日可用时间和语言保存在本机。商店版使用独立沙盒容器内的 QuestlogStore 目录，并单独保存授权；源码安装版使用 `~/Library/Application Support/Questlog/projects.json`，开发启动器使用源码目录配置。WebKit 可以保存本机视图偏好。

在设置中“重置文件访问权限”会忘记全部目录与索引授权并停止其访问，连接与工时仍保留；再次读取需要重新选目录。移除连接会删除该连接的跟踪设置，原项目文件保留。其他本机设置和视图偏好保留至你自行删除，没有服务器副本或远程账户可注销。

商店版内嵌运行时并通过进程内桥接工作，不启动本机 HTTP 服务。WebKit 的本地渲染需要 macOS 出站网络能力，页面仍禁止远程请求与导航。源码版仅在详情打开时启动 `127.0.0.1` HTTP 服务，并校验来源和 JSON 写请求。

打开在线政策和支持链接会使用浏览器，相关网站访问由 GitHub 的政策管理。主动提交的支持问题会发送至 GitHub，公开问题对其他人可见，请勿附带私人项目、凭据或未经处理的截图。Apple 的商店服务及可选系统诊断适用其自身政策。

隐私问题可参考[支持说明](support.md)，敏感安全问题使用[私密报告](https://github.com/jamezzh7/questlog/security/advisories/new)。政策变更在此更新日期。

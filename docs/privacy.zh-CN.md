# 隐私与本地数据

更新：2026 年 10 月 26 日。[English](privacy.md) · [Français](privacy.fr.md)

Questlog 由 jamezzh7 维护，没有 Questlog 注册／密码服务、分析、广告、模型调用或开发者运营的远程后端。带有 iCloud 能力的 Unreleased 版本默认自动同步已连接项目的摘要，可暂停同步或排除项目；普通本地构建不请求 CloudKit。

应用读取已连接的 Markdown 清单、项目目录内显式关联的计划、用于变更检测的文件元数据，以及详情页中的有限项目说明和 Git 提交元数据。不读取聊天正文。文档说明最多四份摘录，每份文档不超过 2 MB，摘录不超过 1,600 字符。选中的 Markdown 若含私人内容，也可能显示在界面中。

Mac App Store 版需要你通过系统对话框选择项目目录，才获得只读访问权。Codex / Claude Code 的项目索引需要单独选择；索引授权不自动授权其中列出的目录。授权通过安全作用域书签在本机保存，以便重启后恢复。不会修改原项目或工具索引。

连接、清单选择、任务范围、工时、每日可用时间、语言和外观偏好、跟踪范围及轻量目标保存在本机。商店版使用独立沙盒容器内的 QuestlogStore 目录，并单独保存授权；源码安装版使用 `~/Library/Application Support/Questlog/projects.json`，开发启动器使用源码目录配置。WebKit 可以保存本机视图偏好。

在设置中“重置文件访问权限”会忘记全部目录与索引授权并停止其访问，连接与工时仍保留；再次读取需要重新选目录。移除连接会删除该连接的跟踪设置，原项目文件保留。其他本机设置和视图偏好保留至你自行删除，纯本地模式不创建云端副本；可选同步的保存与移除方式如下。

商店版内嵌运行时并通过进程内桥接工作，不启动本机 HTTP 服务。WebKit 的本地渲染需要 macOS 出站网络能力，页面仍禁止远程请求与导航。源码版仅在详情打开时启动 `127.0.0.1` HTTP 服务，并校验来源和 JSON 写请求。

## 可选 iCloud 手机伴侣（Unreleased）

iCloud 版默认将已连接、未排除项目的摘要自动发送到 Apple 运营的**你自己的 CloudKit 私有数据库**，最多同时 50 个项目。内容包括随机设备／项目标识、Mac 显示名称、已连接项目和范围名称、跟踪模式、任务统计、来源冲突标记、明确范围的可选百分比及采集时间。不会上传本地路径字段、原始文档、文件名／行号元数据、Git、访问授权、聊天或工时。近况原文需另行开启，最多每项目四段短字段；可能含敏感内容，开启前请核对，常见路径脱敏不能保证移除任意机密。

Questlog 运行且 Mac 唤醒时，发布器约每分钟更新一次，不依赖详情窗口。iPhone 需使用同一 iCloud 账号与环境，核对账号身份后可保存有限离线副本。更换账号会清除手机数据并暂停 Mac 发布，需重新主动开启。开发者没有接收这些快照的应用服务器，iCloud 适用 Apple 的条款和储存规则。

新连接的项目自动加入；保存排除选择或移除连接后，下一次成功同步会移除相应摘要。主动停止后，重启或新增连接也不会自行开启。升级会保留旧版关闭状态、排除选择和云端标识。在原 Mac 的“iCloud 同步”中点击“停止并移除”可删除该 Mac 云端快照；失败会在本机记录并重试，请保持联网直到确认。退出或卸载本身不删除云端记录；若 Mac／同步设置丢失，请使用 Apple 的应用 iCloud 储存管理。手机设置可清除离线副本，之后成功刷新可能重新缓存。详见[配置与限制](icloud-sync.md)。现有仅本地的商店提交与此 Unreleased 功能分开，未来云端版本提交前需重新核对隐私声明。

打开在线政策和支持链接会使用浏览器，相关网站访问由 GitHub 的政策管理。主动提交的支持问题会发送至 GitHub，公开问题对其他人可见，请勿附带私人项目、凭据或未经处理的截图。Apple 的商店服务及可选系统诊断适用其自身政策。

隐私问题可参考[支持说明](support.md)，敏感安全问题使用[私密报告](https://github.com/jamezzh7/questlog/security/advisories/new)。政策变更在此更新日期。

无任务结构时，小窗和菜单栏会从最多四份已知项目文档读取明确状态字段；Git 活动仍仅在详情中读取。
